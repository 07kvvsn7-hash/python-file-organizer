Python File Organizer

A basic Python script to automatically organize files in a folder (such as the Downloads folder) to clear out clutter, categorize items, make them easy to find, and save time.

---

Tech Stack
- Language: Python 3.x
- Built-in Modules: os, shutil (No additional packages required, ready to run out of the box)

---

Features
- Automatically categorizes file types (e.g., images, documents, source code).
- Automatically creates category folders if they do not already exist.
- Lightweight code, easily expandable into an automation system or system tool.
