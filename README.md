Python File Organizer

สคริปต์ Python เบื้องต้นสำหรับช่วยจัดระเบียบไฟล์ในโฟลเดอร์อัตโนมัติ (เช่น โฟลเดอร์ Downloads) เพื่อเคลียร์ไฟล์รกๆ ให้เป็นหมวดหมู่ ค้นหาง่าย ประหยัดเวลา 

---

Tech Stack
* **Language:** Python 3.x
* **Built-in Modules:** `os`, `shutil` (ไม่ต้องลงแพ็กเกจเสริมเพิ่ม รันได้ทันที!)

---

Features
* คัดแยกประเภทไฟล์อัตโนมัติ (เช่น รูปภาพ, เอกสาร, โค้ดโปรแกรม)
* สร้างโฟลเดอร์หมวดหมู่ให้อัตโนมัติหากยังไม่มี
* โค้ดเบาสلاف นำไปต่อยอดเป็นระบบ Automation หรือ System Tool ได้ง่าย
